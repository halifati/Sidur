# Sidur
סידור תפילה עם כוונות

אפליקציית דפדפן לעריכה והדפסה של סידור תפילה – **שחרית, מנחה וערבית לימות החול** – בניקוד מלא,
עם הדגשת **שווא נע**, **קמץ קטן / קמץ גדול** ו**פתח גנובה**, ותצוגה מקדימה מדויקת של הדפים בגודל שנבחר להדפסה.

## הפעלה

אין צורך בהתקנה. פותחים את `index.html` בדפדפן (Chrome / Edge / Firefox / Safari), או מריצים שרת מקומי:

```bash
python3 -m http.server 8000
# ופותחים http://localhost:8000
```

כל השינויים נשמרים אוטומטית בדפדפן. אפשר לייצא/לייבא קובץ גיבוי מלשונית **קובץ**.

## מה אפשר לעשות

- **נוסחים**: אשכנז, ספרד, עדות המזרח. **תפילות**: שחרית, מנחה, ערבית.
- **עריכת ניקוד לכל אות** (במצב עריכה לוחצים על אות):
  - החלפת תנועה (שווא, חטפים, חיריק, צירה, סגול, פתח, קמץ, קמץ קטן, חולם, קובוץ)
  - סוג השווא: אוטומטי / **נע** / **נח**
  - קמץ: אוטומטי / **גדול** / **קטן**
  - פתח גנובה: אוטומטי / כן / לא
  - דגש/מפיק, מתג, רפה, שין ימנית/שמאלית, צבע לאות, החלפת אות
  - מעבר מהיר בין אותיות עם החצים במקלדת
- **הדגשת ניקוד מיוחד** (לשונית **ניקוד**): לכל סוג – שווא נע, שווא נח, קמץ קטן, קמץ גדול (״פתח גדול״), פתח גנובה –
  בוחרים צבע, עובי, הגדלה והזזה. הסימון מופיע גם בהדפסה.
- **זיהוי אוטומטי** של שווא נע (סימוני המקור + כללי הדקדוק: תחילת מילה, שני שוואים, אות דגושה, אותיות זהות,
  אחרי תנועה גדולה), קמץ קטן ופתח גנובה. כל מקרה אפשר לתקן ידנית.
- **הוספת טקסט** בכל מקום (פסקה, הוראה, כותרת) עם בחירת גופן, גודל, צבע, רקע, יישור, הדגשה, רווחים ומרווח שורות.
  בעורך יש מקלדת ניקוד. אפשר גם לערוך, להזיז, להסתיר ולמחוק פסקאות קיימות.
- **עיצוב כללי** (לשונית **טקסט**): גופן (Noto Serif Hebrew, Frank Ruhl Libre, David Libre, Noto Sans Hebrew,
  או כל גופן מותקן), גודל גופן בנקודות, **מרווח בין השורות**, רווח בין פסקאות, יישור, עיצוב כותרות והוראות, טעמי המקרא.
- **גודל הדף** (לשונית **דף**): A4, A5, A6, B5, B6, Letter, גדלי כיס וסידור, או גודל מותאם במ״מ; שוליים
  (כולל שוליים מתחלפים לכריכה), טור אחד או שניים, כותרת עליונה ומספרי עמודים (גם באותיות).
- **תצוגה מקדימה**: התצוגה תמיד מחולקת לעמודים בגודל שנבחר – כך בדיוק זה יודפס. זום, ״גודל אמיתי״ ותצוגת זוגות.
- **הדפסה / PDF**: גודל הנייר נקבע אוטומטית. בחלון ההדפסה: שוליים ״ללא״, קנה מידה 100%, ולהפעיל ״גרפיקת רקע״.
- **תוכן עניינים** עם אפשרות לכלול/להשמיט כל קטע מהסידור המודפס.
- ביטול/חזרה (Ctrl+Z / Ctrl+Y).

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `index.html` | ממשק המשתמש |
| `css/app.css` | עיצוב, עמודים והדפסה |
| `js/hebrew.js` | פירוק אותיות וניקוד, זיהוי שווא נע/נח, קמץ קטן ופתח גנובה |
| `js/render.js` | המרת פסקאות ל-HTML, עורך הטקסט |
| `js/paginate.js` | חלוקה לעמודים (כולל עדכון חלקי אחרי עריכה) |
| `js/app.js` | מצב האפליקציה, לוחות ההגדרות, עריכה, שמירה והדפסה |
| `data/*.js` | טקסט התפילות |
| `fonts/` | גופנים עבריים עם ניקוד (OFL) |
| `tools/build_data.py` | בניית קבצי `data/` מחדש מהייצוא של ספריא |

שווא נע שנקבע ידנית נשמר בטקסט בעזרת תו בלתי נראה (Variation Selector) אחרי הניקוד, כך שהטקסט נשאר תקין.

## מקור הטקסט

הטקסטים לקוחים מ-[ספריא](https://www.sefaria.org) (Siddur Ashkenaz, Siddur Sefard, Siddur Edot HaMizrach),
מתוך הייצוא הציבורי שלהם. לבנייה מחדש:

```bash
mkdir -p /tmp/sef && cd /tmp/sef
for t in "Siddur%20Ashkenaz:ashkenaz" "Siddur%20Sefard:sefard" "Siddur%20Edot%20HaMizrach:edot"; do
  curl -o "${t#*:}.json" "https://storage.googleapis.com/sefaria-export/json/Liturgy/Siddur/${t%%:*}/Hebrew/merged.json"
done
python3 tools/build_data.py /tmp/sef
```

הגופנים: Noto Serif Hebrew, Noto Sans Hebrew, Frank Ruhl Libre, David Libre – רישיון SIL Open Font License.
